# 四組速度與盤距測試總結

測試日期：2026-11-03

比較條件：速度 11、12 cm/s，盤距 4、15 cm。

## 實驗目的

用同一套方法找出：

1. 空軌道的偽陽性。
2. 橘、綠、黃三色的判斷正確性。
3. 每10 cm的穩定辨識位置與可靠終點。
4. 軌道速度對取樣與辨識的影響。
5. 盤距對多盤追蹤、漏盤與重複計盤的影響。

## 實驗前固定條件

每組測試都必須保持以下條件相同，否則不能直接比較：

- 使用同一台相機、解析度、曝光、焦距及安裝位置。
- 使用同一個模型版本、confidence threshold及tracker設定。
- 使用相同ROI、entry、exit與距離刻度。
- 使用相同的亮度、對比及HLS／Lab顏色設定。
- 保持燈光、輸送帶背景及反光條件一致。
- 盤子順序固定為橘、綠、黃；若測試其他順序，需另開一組紀錄。
- 每次只更改一個主要變因，例如速度或盤距。

## 資料夾命名

資料夾名稱必須包含速度與盤距：

`日期時間_v速度cm_s_d盤距`

例如：

- `20261103_104503_v12cm_s_d4`
- `20261103_103936_v12cm_s_d15`
- 空軌道測試加上 `_空盤`。

## 實驗操作步驟

### A. 每組速度與盤距測試

1. 設定軌道速度及盤子中心間距，實際用尺確認，不只使用控制器顯示值。
2. 啟動相機及自檢程式，確認畫面、ROI與距離方向正確。
3. 先讓空軌道運轉約30秒，確認畫面沒有殘留盤子或舊tracker。
4. 按 `B` 啟動新的橘、綠、黃評估週期。
5. 依序放入橘、綠、黃盤，人工記錄實際盤數、顏色、速度與盤距。
6. 觀察畫面是否依序出現P1、P2、P3。`P`代表盤次，`T`代表tracker；tracker改變不應增加實際盤數。
7. 讓所有盤子完整通過0～120 cm，不要在中途停止或改變速度。
8. 按 `S`保存；若直接結束則按 `Q`，確認資料夾中已產生CSV與 `analysis_summary.md`。
9. 若出現錯色、低信心、新tracker或重複盤次，保留自動異常圖片；必要時按 `A`手動保存當下畫面。
10. 每個條件至少重複到20盤，三種顏色盡量各有相同盤數。三盤測試只能用於初步比較。

### B. 空軌道偽陽測試

1. 移除所有盤子，但保持輸送帶、燈光、反光與正式運作狀態。
2. 按 `B`開始記錄，空軌道至少連續運轉60分鐘。
3. 測試期間不要遮掉平常會出現的反光，也不要刻意降低燈光。
4. 保存所有被系統建立成P盤次的事件及異常圖片。
5. 結束後記錄實際測試秒數、總推論frame、零偵測frame、偽盤數及偽框數。

## 五項判定方法

### 1. 偽陽性

空軌道中任何被建立成盤次的事件都算偽盤：

`偽盤率（次／小時） = 偽盤數 ÷ 測試秒數 × 3600`

建議標準：正式目標為0次／小時；初期最低標準為少於1次／小時。測試時間不足60分鐘時只能列為初步結果。

### 2. 顏色正確性

人工真值為實際放入的橘、綠、黃盤：

`顏色正確率 = 顏色判斷正確的盤次 ÷ 成功偵測盤次`

必須同時查看三色混淆結果，不能只看總正確率。建議每種顏色正確率都至少95%，且不能有某一色持續被判成另一色。

### 3. 穩定位置

每10 cm分開計算：

- 該區間所有實際盤次都必須被偵測。
- 每盤平均至少5筆 observation。
- confidence p10至少0.70。
- 盤次顏色多數決正確率至少95%。
- 不應在該區間頻繁更換tracker或誤建新P盤次。

連續符合條件的最遠區間終點為暫定可辨識距離。正式主要判斷終點應再往前保留10 cm，最後10 cm作緩衝區。

### 4. 速度

至少測試11、12 cm/s；若需要找極限，再增加更快速度。每個速度使用相同盤距、盤數及環境。

`理論每盤每10 cm取樣數 = 有效FPS × 10 ÷ 速度（cm/s）`

比較每個速度的盤次召回率、顏色正確率、tracker數、重複計盤率及穩定終點。速度較慢但結果沒有改善時，不應因直覺選擇較慢速度。

### 5. 盤距

在相同速度下分別測試4、15 cm。比較：

- 同一frame同時出現1、2、3個盤子的比例。
- tracker切換數與新tracker事件。
- 是否將同一盤誤建成新的P盤次。
- 漏盤率、顏色正確率與穩定終點。

選擇能維持盤次一對一、沒有重複計盤且範圍達標的最小盤距。

## 驗收順序

1. 先用空軌道排除偽陽性。
2. 再確認三色在近距離能正確分類。
3. 接著找出每10 cm的穩定終點。
4. 在固定盤距下比較速度。
5. 在固定速度下比較盤距。
6. 選出候選設定後，再用至少20盤加60分鐘空軌道做最終複驗。

## 盤距影響

盤距的影響比速度明顯：

- 兩個 d15 測試的顏色正確率都是約97%，而且穩定範圍都能到80 cm。
- 兩個 d4 測試的建議主要終點都只有約60 cm。
- 11 cm/s、d4在約115 cm誤建出只有兩筆 observation 的P4，表示近盤距下遠端斷線可能造成重複計盤。
- d4在同一個frame同時出現多盤時，tracker切換與顏色錯誤較明顯。

因此，目前盤距建議至少15 cm。若盤距必須小於15 cm，需優先改善多物件配對與pass重新連接邏輯，不能只靠降低軌道速度。

## 速度影響

- d15條件下，11與12 cm/s的穩定範圍相同，都是0～80 cm。
- d15顏色正確率也幾乎相同：11 cm/s為97.3%，12 cm/s為97.1%。
- 12 cm/s、d15只使用16個tracker，少於11 cm/s、d15的21個，且中位有效FPS較高。
- d4條件下，11 cm/s反而比12 cm/s出現更多錯色與疑似誤建盤次。

目前沒有證據顯示從12 cm/s降到11 cm/s能改善辨識。速度差異的影響小於盤距與追蹤穩定性的影響。

## 距離共同趨勢

- 0～70 cm：d15在兩種速度下都穩定。
- 70～80 cm：適合作為d15緩衝區，不建議作為唯一判斷區。
- 80～90 cm：confidence p10開始明顯下降。
- 90～100 cm：取樣數下降，部分測試開始漏盤。
- 100 cm以後：即使偶爾還有框，也常出現低信心、不連續、tracker切換或錯色，不能用單次最遠距離宣稱為可靠範圍。

## 空軌道偽陽測試

空軌道測試資料夾從建立到保存約5分55秒，期間結果如下：

| 指標 | 結果 |
|---|---:|
| 推估測試時間 | 約355秒 |
| observation | 0 |
| 系統建立盤次 | 0 |
| 異常照片 | 0 |
| 觀測到的偽盤 | 0 |
| 觀測偽盤率 | 0次／小時 |

- 這次沒有反光或背景被記成盤子，短時間結果良好。
- 目前程式只記錄有偵測結果的 observation，零偵測frame沒有逐次保存。因此「有效推論frame為0」不能用來證明API全程完成推論。
- 約6分鐘樣本不足以正式宣稱長時間偽陽率為零；正式驗收建議空軌道至少連續測60分鐘。
- 後續應記錄總推論frame、零偵測frame及偽盤數，才能可靠計算 `false passes/hour`。

## 最終建議

目前四組之中，建議優先採用：

| 設定 | 建議值 |
|---|---:|
| 軌道速度 | 12 cm/s |
| 最小盤距 | 15 cm |
| 主要判斷範圍 | 0～70 cm |
| 緩衝區 | 70～80 cm |
| 80 cm以後 | 不作主要計數或最終顏色判斷 |
| 空軌道結果 | 約6分鐘、0次偽盤；需60分鐘複驗 |

選擇12 cm/s、d15的原因：穩定範圍與11 cm/s、d15相同，顏色正確率只差0.2個百分點，但tracker較少、FPS較高，也能維持較高輸送速度。

## 限制

- 每組目前只有約3個原始盤次，樣本仍不足以正式定案。
- 下一階段應在12 cm/s、d15條件下至少測20盤，並以每10 cm盤次召回率確認0～70 cm是否持續達標。
- 11 cm/s、d4包含疑似誤建的P4，因此其整體顏色正確率同時反映了遠端重複計盤問題。
